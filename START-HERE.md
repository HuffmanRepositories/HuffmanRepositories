# Start Here — HuffmanRepositories

Welcome to the public portfolio index for Robert Huffman's open-source work under HuffmanRepositories.

## What this repository is
This repository is the profile and discovery front door. It connects the public mission hub, the technical projects, and the public ecosystem guide. It is not the canonical home for every project's specifications or source code.

## First 15 minutes
1. Read [README.md](README.md) for the portfolio overview.
2. Visit [Open Source AI Independence](https://github.com/HuffmanRepositories/Open-Source-AI-Independence) for the mission, roadmap, and community coordination.
3. Visit the [Huffman Ecosystem Guide](https://github.com/HuffmanRepositories/Huffman-Ecosystem-Guide) for beginner orientation and safe-use guidance.
4. Use the project map to select the repository that owns the technical subject.
5. Read that repository's README, status, security policy, license, and contribution guidance before relying on it.

## How to contribute
Use this profile repository for account-level navigation and portfolio presentation. Submit technical changes to the project that owns the relevant code, schema, fixture, or research. Avoid duplicating content across repositories; link to the canonical source instead.

## For AI agents
Read [AGENTS.md](AGENTS.md). Treat this repository as a navigation index. Verify current repository contents and status before making claims. Do not infer that a listed project is production-ready, certified, or actively maintained solely because it appears here.

## Portfolio principles
Evidence over assertion; clear ownership; minimal duplication; responsible disclosure; human review; and honest maturity labels.
