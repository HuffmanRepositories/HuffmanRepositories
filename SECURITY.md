# Security Policy

This repository is a public portfolio and discovery profile. It is not a hosted security service or agent runtime.

## Reporting
Do not publish credentials, exploit details, personal information, or sensitive reproduction data in public issues. Use GitHub's private vulnerability reporting workflow if enabled for the affected repository. Otherwise contact the maintainer through the GitHub profile and request a private disclosure channel.

## Safe research
- Respect authorization, privacy, and applicable law.
- Do not commit secrets, private keys, personal data, or non-public third-party material.
- Treat public-source leads as unverified until corroborated.
- Preserve provenance and distinguish facts from analytical judgments.
- Do not interpret repository content or successful CI as a security guarantee.
